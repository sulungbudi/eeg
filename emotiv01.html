Catatan teknis & cara menemukan serial dongle

Kunci AES. Untuk EPOC X/EPOC+ via dongle, kunci dibentuk dari 4 karakter terakhir serial USB dongle (s1 = karakter terakhir): s1 s2 s4 s4 s2 s1 s2 s4 s1 s4 s3 s2 s1 s2 s2 s3. Contoh: serial UD20221202006756 → kunci 6566565666756557. WebHID tidak bisa membaca serial perangkat, jadi app ini mencoba seluruh kemungkinan 4 karakter dan memilih kunci yang membuat counter paket (byte 0) naik teratur.

Menemukan serial (bila ingin diisi manual). Windows: Device Manager → Universal Serial Bus controllers atau Human Interface Devices → perangkat dengan VID_1234&PID_ED02 → Properties → Details → Device instance path. Bagian setelah PID_ED02\ (pada entri tanpa MI_) adalah serialnya. Linux: lsusb -v -d 1234:ed02 | grep iSerial. macOS: System Information → USB → EEG Signals → Serial Number.

Format paket. 32 byte per paket. Byte 0 = counter, byte 1 = tipe paket. EEG 14 kanal ada di byte 2–15 dan 18–31, tiap sampel 2 byte little-endian, dikonversi seperti CyKit: µV = 4201.0256 + 0.128205 × (raw − 32768). Offset ±4200 µV mengikuti konvensi ekspor Emotiv, jadi buang rata-ratanya (high-pass) sebelum analisis. Paket dengan tipe berbeda dari tipe dominan (kemungkinan data gerak/motion) dilewati.

Yang belum didekode. Baterai, kualitas kontak, dan sensor gerak belum didekode (sebelumnya baterai salah dibaca dari byte EEG, itulah sebabnya angkanya berubah-ubah). Laju sampel default EPOC X via dongle 128 Hz, bisa 256 Hz bila diubah dari Emotiv Launcher.

Windows. Jangan ganti driver dongle ke WinUSB/Zadig. WebHID memakai driver HID bawaan. Tutup EmotivPRO/Launcher agar dongle tidak dipakai aplikasi lain.

Validasi. Skala µV mengikuti rekayasa balik komunitas (CyKit), bukan dokumentasi resmi. Untuk publikasi, bandingkan dulu dengan rekaman EmotivPRO.

Urutan kanal: AF3, F7, F3, FC5, T7, P7, O1, O2, P8, T8, FC6, F4, F8, AF4.
